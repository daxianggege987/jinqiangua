  • 设备：iPhone / iPad（若支持）。

三、常见问题（FAQ）

Q1：为什么需要网络？
部分功能或第三方服务（如广告加载）可能需要网络；离线时本地学习内容仍可浏览，但广告等依赖网络的功能可能不可用。

Q2：数据保存在哪里？
起卦记录、学习进度、笔记等默认保存在本机。卸载应用或清除数据可能导致记录丢失，重要内容请自行备份。

Q3：广告过多或无法关闭？
广告由第三方 SDK 按策略展示；若您认为展示异常，请尝试更新至最新版本、检查网络，并可通过邮件向我们反馈具体情况（含系统版本与截图）。

Q4：闪退或界面异常？
请尝试重启应用、重启设备或更新系统；若问题持续，请通过下方邮箱联系我们，并说明设备型号、系统版本与操作步骤。
